# Inventory Management (Python stdlib)
รัน: `python api/index.py` แล้วเปิด http://localhost:8000
บัญชีทดสอบ: admin / admin1234 , staff / staff1234 , สมัครใหม่ = customer
Deploy: `vercel --prod` (ตั้ง env SECRET ให้เป็นค่าสุ่มยาวๆ)
หมายเหตุ: บน Vercel ไฟล์ระบบเขียนได้เฉพาะ /tmp ข้อมูลจึงไม่ถาวร ถ้าต้องถาวรให้ใช้ DB ภายนอก (ต้องขออนุญาตอาจารย์)
